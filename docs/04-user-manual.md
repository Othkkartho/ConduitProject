# 04. Conduit 사용자 매뉴얼

> 이 문서는 앱/웹 UI 내부의 **사용자 매뉴얼 모달(`F1` 또는 상단 `매뉴얼` 버튼)** 과 동일한 내용을 제공합니다. 데스크톱 앱에서는 상단 메뉴 바의 **도움말 → 사용자 매뉴얼** 에서도 열 수 있습니다.

---

## 1. 시작하기 (Desktop 앱 vs Web 서버 모드)

- **Desktop 앱 모드 (Tauri v2)**: 네이티브 창과 메뉴 바(`보기`, `도움말`)를 사용하며, Rust 코어와 Binary IPC 채널로 직접 통신해 최고 성능을 제공합니다. 자격 증명 마스터 키는 OS 키체인에 안전하게 보관됩니다.
- **Web 서버 모드 (Axum)**: `conduit-web` 서버를 띄워 브라우저에서 접속합니다. 단일 WebSocket 연결 위에서 5바이트 바이너리 멀티플렉싱으로 여러 터미널 탭과 분할 화면을 동시에 구동합니다.

---

## 2. 멀티 프로토콜 & 간편 SSH 연결

- **간편 SSH 연결 (`Ctrl+Shift+E` 또는 상단 `새 연결` 버튼)**: `test@192.128.0.1` 또는 `test@192.128.0.1:2222`를 입력한 뒤 비밀번호 입력 창(`Password for user@host`)에 비밀번호를 입력하면 북마크 저장 없이 즉시 연결됩니다(`Remember` 체크 시 현재 세션 동안 기억).
- **연결 후 북마크 저장 (`Ctrl+Shift+D`)**: 터미널 헤더의 북마크 저장 버튼 또는 `Ctrl+Shift+D`를 누르면 감지된 호스트명(hostname), IP, 포트, 사용자명이 자동 채워져 비밀번호만 다시 입력해 북마크로 저장할 수 있습니다.
- **세션 북마크 추가/편집**: 새로운 북마크 생성은 **세션 북마크** 패널의 **새 북마크 / 연결(`+`)** 버튼 또는 폴더/빈 공간 우클릭 메뉴에서만 수행할 수 있습니다(마우스가 창 밖으로 나가도 닫히지 않으며 `X`, `취소`, `Esc`로 닫기).

---

## 3. 드래그 화면 분할(최대 2×2) & 하단 Broadcast

- **드래그 자동 분할**: 상단 탭, 터미널 패인 헤더, 또는 북마크 항목을 드래그하여 다른 터미널 창의 좌/우/상/하 가장자리에 놓으면 자동으로 수평/수직 분할됩니다(한 탭 최대 **2×2 = 4개**). 중앙에 놓으면 위치 교환, 패인 헤더를 상단 탭 바에 놓으면 새 탭으로 분리됩니다.
- **하단 Broadcast 입력 창 (`Ctrl+Shift+M`)**:
  1. **전체 세션 Broadcast**: 열려 있는 모든 탭의 세션에 동시 전송
  2. **현재 화면 세션만 Broadcast**: 현재 활성 탭에 보이는 분할 패인에만 전송
  3. **선택된 세션만 실행**: 현재 포커스된(선택된) 단일 세션에만 전송

---

## 4. VS Code 스타일 패널 레이아웃 & 중첩 폴더 북마크

- **레이아웃 토글 & 아이콘 바**:
  - 상단 우측 레이아웃 아이콘으로 좌측(`Ctrl+B`) / 하단(`Ctrl+J`) / 우측(`Ctrl+Alt+B`) 패널을 켜고 끌 수 있습니다.
  - 좌/우/하단 Activity Bar에는 아이콘만 표시되며 마우스를 올리면 기능명과 단축키가 나타납니다.
  - 아이콘(예: 세션 북마크)을 드래그해 오른쪽 또는 하단 바에 놓으면 해당 위치로 이동합니다.
- **다단계 폴더 트리 & 드래그 위치 이동**: 폴더/세션 북마크를 드래그하여 다른 폴더로 이동(폴더 이동 시 내부 하위 폴더·세션 전체 이동)하거나 같은 폴더 내 우선순위를 변경할 수 있습니다. 폴더 우클릭으로 **하위 폴더 추가** / **이 폴더에 세션 추가**를, 빈 공간 우클릭으로 루트 추가를 수행할 수 있으며 세로 가이드 선으로 들여쓰기가 구분됩니다.
- **삭제 확인 & Import / Export**: 북마크·폴더(및 원격 SFTP 항목) 삭제 시 확인 창이 표시되며, 사이드바 상단의 내보내기(`↓`)/가져오기(`↑`) 버튼으로 JSON 백업(비밀번호 포함 옵션, 병합/덮어쓰기 지원)이 가능합니다.

---

## 5. SFTP 파일 탐색기

- 현재 포커스된 패인이 **SSH 세션**일 때 하단 Activity Bar의 **SFTP 탐색기** 아이콘(`Ctrl+Shift+S`)을 열면 기존 SSH 연결 위에서 원격 파일을 탐색·업로드(드래그 앤 드롭)·다운로드할 수 있습니다.

---

## 6. 설정 & 단축키

- **설정 (`Ctrl+,`)**: 컬러 스킴, Nerd Fonts/합자, 커서 스타일, **세션 종료 시 동작**(바로 닫기 vs 종료 전 한 번 물어보기)을 설정할 수 있습니다.

| 단축키 | 기능 |
|---|---|
| `F1` | 사용자 매뉴얼 열기 |
| `Ctrl + B` / `Ctrl + J` / `Ctrl + Alt + B` | 좌측 / 하단 / 우측 패널 토글 |
| `Ctrl + Shift + B` / `M` / `S` | 북마크 / Broadcast / SFTP 뷰 토글 |
| `Ctrl + Shift + T` | 새 로컬 터미널 탭 |
| `Ctrl + Shift + E` | 간편 SSH 연결 (`user@host`) |
| `Ctrl + Shift + D` | 현재 세션을 북마크에 저장 |
| `Ctrl + Shift + F` | 터미널 내 문자열 검색 |
| `Ctrl + ,` | 환경 설정 열기 |
